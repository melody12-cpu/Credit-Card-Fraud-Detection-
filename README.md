# Credit-Card-Fraud-Detection-

Credit card fraud is a growing financial problem that costs consumers and businesses billions of dollars each year. Because fraudulent transactions make up only a very small percentage of all credit card purchases, detecting them can be challenging. A machine learning model is well suited for this task because it can analyze large amounts of transaction data, recognize patterns associated with fraud, and make predictions on new transactions more efficiently than manual review.

To create this project, I used a dataset containing thousands of credit card transactions labeled as either fraudulent or legitimate. The data was imported into Google Colab using Python and processed with the pandas and scikit-learn libraries. A logistic regression model was then built using a machine learning pipeline, and class weights were added to reduce the effect of the highly imbalanced dataset, where legitimate transactions greatly outnumbered fraudulent ones.

After training, the model was evaluated using precision, recall, a confusion matrix, and an ROC curve. The model achieved a recall of approximately 89%, meaning it successfully detected 87 out of 98 fraudulent transactions in the test set. However, the precision was about 45%, indicating that many transactions predicted as fraud were actually legitimate. The confusion matrix showed that the model correctly classified 56,756 legitimate transactions and 87 fraudulent transactions, while incorrectly flagging 108 legitimate transactions as fraud and missing 11 fraudulent transactions. The model also achieved an ROC AUC score of approximately 0.97, which indicates that it was effective at identifying fraudulent and legitimate transactions overall.

One of the biggest challenges was the variance in the dataset. Since fraudulent transactions were only a small minority of the data, the model learned to prioritize finding as many fraud cases as possible, which resulted in more false positives. Increasing the class weight did not significantly improve the results because there were still too few fraud examples for the model to learn from. In the future, this project could be improved by using a larger and more balanced dataset,or testing more advanced machine learning algorithms. Overall, the project demonstrated that machine learning can be an effective tool for detecting credit card fraud while also showing the challenges of working with real-world data.
